# 쿠팡 파트너스 간편 링크 — 기존 로그인 크롬 확장 프로그램 1건 실험

이 코드는 **자신이 이미 정상 로그인한 일반 Chrome**에서 간편 링크 화면을 보조하는, 사용자 클릭 기반 실험용 확장 프로그램입니다. 쿠팡 Open API를 쓰지 않으며 쿠키·비밀번호·로컬스토리지 세션을 읽거나 GitHub 서버에 보내지 않습니다.

## 설치 (Windows)

1. GitHub에서 실험 브랜치 `test/github-only-pipeline-20261031`를 선택하고 Code > Download ZIP을 누릅니다.
2. ZIP의 압축을 풉니다. `experiments/partners-chrome-helper/` 폴더를 찾습니다. 이 폴더에 `manifest.json`, `popup.html`, `popup.css`, `popup.js`가 있는지 확인하세요.
3. 평소 쿠팡 파트너스에 정상 로그인되는 **일반 Chrome** 주소창에 `chrome://extensions`를 넣고 개발자 모드를 켭니다.
4. `압축해제된 확장 프로그램을 로드합니다`를 눌러 위 `partners-chrome-helper` 폴더를 선택합니다. 필요하면 퍼즐 아이콘에서 확장을 고정하세요.
5. 확장 아이콘을 눌러 GitHub에서 추출한 **일반 쿠팡 상품 URL**을 붙여넣습니다. 원본 뽐질 `link.coupang.com/a/...` 단축링크는 이 확장의 입력이 아닙니다. 별도 GitHub `gh_only/partners_link_prep.py`로 상품 번호+itemId+vendorItemId만 남긴 URL을 넣으세요.
6. `① 간편 링크 화면 열기`를 누릅니다. 로그인된 상태로 접속되는지 확인합니다. 구형 북마크 URL이 잘못된 페이지로 연결되면, 일반 쿠팡 파트너스 사이트 내 메뉴에서 `간편 링크 만들기` 화면으로 **직접** 이동하세요.
7. 그 탭에서 확장 아이콘을 다시 열어 `② 상품 URL 입력`을 누릅니다. 입력이 성공했다고 나오면 화면의 `쿠팡 URL`에 올바른 상품이 들어갔는지 직접 확인하세요.
8. `③ 공식 링크 생성 버튼 누르기`를 눌러 사이트 자체의 `링크 생성` 버튼을 클릭합니다. 실패하면 직접 버튼을 눌러도 됩니다. 결과가 화면에 표시되면 `④ 생성된 내 링크 읽기`를 눌러 단축 URL을 확인하세요.
9. 결과의 상품이 원본 **productId/itemId/vendorItemId**와 일치하고, 링크가 **내 쿠팡 파트너스 계정에서 생성된 것**임을 사이트에서 확인한 다음 복사해서 테스트합니다. 이 확장은 소유권을 단독 검증하지 못합니다.

## 휘카레 재현용 일반 상품 URL

```text
https://www.coupang.com/vp/products/9217210892?itemId=27232840915&vendorItemId=94199974724
```

## 현재 상태 및 제한

- GitHub-hosted 익명 접속에서 쿠팡 파트너스 `HTTP 403` 재현됨. 크롬 확장은 **GitHub 서버가 아니라 사용자 PC에서 이미 정상 로그인된 Chrome 탭**에만 작동합니다.
- 이 확장 자체를 GitHub Actions에서 실행하는 건 불가능합니다. PC를 끄고 처리하려면 정상 접속이 가능한 **상시 가동 VM**의 별도 인증 브라우저 환경이 필요하며, 그 VM의 사이트 접근과 이용 조건부터 확인해야 합니다.
- 확장 UI의 입력칸/링크 생성 버튼 식별은 **아직 실사용 사이트에서 검증하지 않았습니다**. 실패 시 확장이 출력하는 `INPUT_UNCONFIRMED` 또는 `GENERATE_BUTTON_UNCONFIRMED` 상태 코드와 **쿠키가 보이지 않는 간편 링크 화면 스크린샷**만 공유하면 선택자를 수정할 수 있습니다.
- 보안: 호스트 권한은 `https://partners.coupang.com/*`만 부여, 쿠팡 로그인 페이지 접근 권한 없음. 기밀 정보, `document.cookie`, 비밀번호나 사용자 식별자를 읽지 않음. 외부 서버 호출 없음. 상품 URL만 브라우저 로컬 확장 저장소에 보관.
- 고의로 CAPTCHA를 자동 조작하거나 권한 차단을 우회하는 기능이 없습니다. 자동 게시, 크론, GitHub 클라우드 링크 생성, 사용자 계정 로그인 자체는 모두 미구현.
- 공식 API 없이도 쿠팡 파트너스 사이트에서 간편 링크 수동 생성은 가능하나, 사이트가 이 방식의 지속적 자동화를 지원하는지는 별도 확인이 필요합니다.

## 코드 검증

GitHub Actions: `.github/workflows/partners-chrome-helper-tests.yml`에서 JS 구문 검사, Manifest V3 권한 최소화, 명시적 수동 클릭, 쿠키 접근 금지 등 오프라인 테스트 통과. 실제 일반 Chrome 사이트 동작은 **사용자 수동 실험 대기 중**.

## 0.2 수정 (2026-11-01): 실제 쿠팡 화면 ③/④ 오류 피드백 반영

- 사용자의 스크린샷에서 **① 간편 링크 화면 정상 접근, ② 쿠팡 URL 정상 입력** 확인. 파란 `링크 생성` 버튼이 보이지만 기존 정확한 글자 비교가 `GENERATE_BUTTON_UNCONFIRMED`를 반환한 문제를 수정했음.
- ③: 정확한 상품 URL이 실제 페이지 입력칸에 있는지 확인한 뒤, 버튼의 `innerText/textContent/value/aria-label/title`을 검사하고 숨겨진 문자, 불규칙 공백, 중첩 글자에 견고하게 대응. 후보가 0개 또는 여러 개면 클릭하지 않음.
- ④: 생성 결과가 input/anchor뿐 아니라 모달/일반 텍스트에 출력되어도 `https://link.coupang.com/a/...` 등 알려진 패턴만 추출. 쿠키, 페이지 원문, 로그인 식별값 저장/전송 안 함. 후보가 여러 개면 선택하지 않고 진단만 보여줌.
- GitHub에서 정적 테스트를 통과해도 **실제 쿠팡 로그인 화면에서의 선택자 동작은 아직 재검증되지 않음**. 클릭 후 결과를 확인할 필요 있음.
- 구버전 설치했으면 `partners-chrome-helper-v0.2.zip`을 풀어 새 폴더로 교체하고 크롬의 `chrome://extensions`에서 기존 확장을 **삭제**한 뒤 새 `partners-chrome-helper` 폴더를 로드하면 확실함. 또는 동일한 경로에 파일을 덮어쓰고 확장 카드의 새로고침을 클릭.
- 정상 화면이라면 `② 상품 URL 입력` → `③ 공식 링크 생성 버튼 누르기` → 결과창 표시 확인 → `④ 생성된 내 링크 읽기` 순서로 시도. ③ 결과가 계속 실패하면 팝업에 표시되는 짧은 `status`, `relevantButtonLabels` 부분만 공유하면 다음 선택자를 개선할 수 있음.

## v0.3 변경 (① 페이지 열기 버튼 문제 수정)

- 새 확장 설치 직후 저장된 상품 URL이 빈 상태여도 **① 간편 링크 페이지 열기는 항상 작동**합니다.
- ①은 로그인된 기존 일반 Chrome에 `https://partners.coupang.com/#affiliate/ws/link-to-any-page` 탭을 여는 동작만 합니다. **상품 URL 검사는 ②에서만** 필수입니다.
- 입력한 URL이 정상일 때만 선택적으로 저장하며, 저장 오류가 나도 ① 탭 열기를 막지 않습니다. 잘못된 URL이라면 탭을 열고 ② 실행 전에 올바른 상품 URL을 붙여넣도록 알려줍니다.
- 기존 확장 삭제 후 v0.3 폴더를 다시 설치하면 상품 URL 입력값이 초기화될 수 있습니다. **처음부터 ②를 사용할 때는 위 테스트 상품 URL을 다시 붙여넣으세요.**
- ① 수정은 별도의 Node UI 모의 테스트로 네 가지 경우(빈값/잘못된값/정상값/저장 오류)를 검증합니다. 사용자 크롬 실사이트 동작은 설치 후 확인이 필요합니다.
